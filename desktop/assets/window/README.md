# Window caption glyphs

Minimize, maximize, restore and close for the caption buttons the app draws
where it owns the title bar: on Windows, and on Linux under client-side
decorations. They are drawn for this project on a 10px grid with 1px lines,
after the proportions of the Windows 11 caption glyphs, so the buttons read as
the platform's own without depending on a system icon font. macOS keeps its
native traffic lights.
