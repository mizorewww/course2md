## 实际操作（macOS）

使用独立验收配置和测试课程，没有修改用户的默认配置或课程目录。

- 启动进入课程库，封面卡片支持从图片或标题打开笔记。
- 在线入口使用「预览课程」，本地入口使用系统视频选择器。YouTube 链接通过回车读取真实封面、标题、作者、时长。
- 修改已预览链接会清除旧信息；读取过程中改变输入后，旧请求不会覆盖新输入。无效链接保留输入并提供重试。
- 本地视频自动读取信息和封面；选择后显示紧凑的文件名和「更换视频」，归档目标留在可见范围内。
- 实际生成带同名字幕的本地视频笔记，完成后自动打开阅读页，封面文件和文件夹归属正确落盘。
- 创建文件夹、回车保存、重命名、将课程移出和移入、退出再启动后恢复分组，均已操作通过。
- 删除含课程的测试文件夹后，课程回到未分类，原 course.md 仍然存在。
- 搜索无结果可清空恢复；阅读后返回原列表；完成后再次添加课程不沿用刚完成的来源。

- 未保存的目录草稿不会影响课程库；保存后切换到新目录，恢复设置后原课程重新出现。
- 单次关闭 JSON 导出不会改变默认设置，返回添加页仍保留本次选择。
