# v3.0.0-alpha.6：界面整理

3.0.0 的第六个预览版。这一版集中整理界面：引导、设置、笔记库、阅读器、首页和对话框都按 Material 规范逐页检查并修改；删除服务后不再自动换用其他服务。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 删除服务后先问你

- 草稿选中的 AI 或语音识别服务被删除后，不再悄悄改用默认服务：卡片上会提示，可选「使用默认服务「X」」或「选择服务」。选定之前，「开始转换」「重新生成」和「整理选中的视频」都不可用，不会把请求发到你没选的服务上。
- 旧任务里保存的错误信息按新的说法显示；模型错误显示模型名称（如「Qwen3 1.7B」），不再是内部编号。

## 界面

- **配色**：可修复的问题（缺少模型、缺少或已删除的服务）统一用琥珀色提示，并附带修复按钮；红色只用于无法直接修复的失败。深色主题下的警告提示不再发灰；多个配色中警告和成功文字的对比度提高到至少 4.5:1。
- **引导**：最后一步的标题与实际状态一致；选择识别模型时显示用途和下载大小；可以稍后再设置的步骤都有「稍后设置」；没有语音服务时不会卡在最后一步。
- **设置**：下拉框按内容调整宽度，过长时悬停可看完整内容，模型状态显示在下方；检查失败时给出对应的修复方式；窄窗口下导航文字完整显示；服务与账号的状态标记位置和用词统一。
- **笔记库**：工具栏改为中性配色，排序在窄窗口下保留文字，「文件夹」与「按文件夹分组」使用不同图标，列表显示视频时长。
- **阅读器**：标题只显示一次；本地视频的「从此处观看」在装有 IINA、VLC 或 mpv 时直接从该时间打开，否则打开默认播放器并提示跳到哪个时间；截图页与笔记同宽并保留搜索。
- **首页与任务页**：任务区域统一叫「正在处理」，任务页与首页同宽；运行中任务的操作放在一起；不再同时显示重复的标记和提示；封面显示时长；全应用使用同一种日期格式；选择本地文件后自动预览；笔记名称留空时使用视频本身的名称。
- **对话框**：「完全磁盘访问」引导在等待步骤以「我已打开开关」为主要操作，会重新检查并继续；YouTube 登录说明合并为一段。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui@alpha`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.6/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [安装程序](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.6/course2md-desktop-windows-x64-setup.exe) · [便携版 ZIP](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.6/course2md-desktop-windows-AMD64.zip) | 运行安装程序，无需管理员权限，会原地升级之前的安装；未签名时 SmartScreen 会先询问（「更多信息 → 仍要运行」）。或完整解压 ZIP 后打开 `course2md-desktop.exe` |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.6/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

设置、模型缓存和笔记库都会保留。在「设置 → 应用」确认版本 `3.0.0-alpha.6`；CLI 使用 `course2md --version` 确认。

## 验证范围

每一页及其各种状态都在 macOS 上实际运行并截图（中文深色、英文浅色，1280 与 720 宽），经过多轮独立评审；删除服务后的拦截覆盖了所有开始任务的入口。Windows 与 Linux 只经过自动测试和 Windows 安装程序的 CI 测试；真实账号的登录与下载尚未验证。

## English

**course2md 3.0.0-alpha.6: interface pass.** Onboarding, Settings, the library, the reader, home and the dialogs were checked page by page against Material and reworked.

**A deleted service asks first.** When a draft's chosen AI or speech service has been deleted, the card asks before anything runs: "Use default service "X"" or "Choose service". Start, Regenerate and "Convert selected videos" stay disabled until you choose, so no request goes to a service you didn't pick. Saved errors show current wording, and model errors name the model instead of its id.

**Interface:**
- **Colours:** problems with a fix (missing model, missing or deleted service) are amber with their repair; red is kept for failures with nothing to repair. Warning notices no longer look grey in dark mode, and warning and success text reads at 4.5:1 or better.
- **Onboarding:**
  - The last step says what is actually ready.
  - Model choices show what they're for and their download size.
  - Steps that can wait offer "Set up later".
  - Onboarding no longer dead-ends without a speech service.
- **Settings:**
  - Dropdowns fit their values and show the full value on hover.
  - Failed checks offer their fix.
  - Navigation fits narrow windows.
- **Library:** a neutral toolbar, distinct icons, and video lengths.
- **Reader:**
  - The title shows once.
  - "Watch from here" on a local video opens IINA, VLC or mpv at that time when installed; otherwise it opens the default player and says where to skip to.
  - Screenshots share the note's width and keep search.
- **Home and Tasks:**
  - Both are titled "In progress" and use the same width.
  - No duplicate chips or banners.
  - Covers show lengths.
  - One date format app-wide.
  - Local files preview automatically.
  - An empty note name uses the video's name.
- **Dialogs:**
  - The Full Disk Access guide leads with "I've turned it on", which checks again and moves on.
  - The YouTube sign-in explanation is one notice.

**Install or upgrade:**
- `brew upgrade --cask course2md-gui@alpha`, or `brew install --cask mizorewww/tap/course2md-gui@alpha` for a first install.
- `brew install mizorewww/tap/course2md-alpha` for the standalone CLI.
- The downloads above; Windows has an installer.

Prereleases don't replace the stable release, and AUR skips them.

**Testing so far:**
- Every page and state was run and captured on macOS in two languages, light and dark, at two widths, then reviewed independently.
- Windows and Linux are covered by automated tests only.
- Logging in and downloading with real accounts has not been checked yet.

Please report any issues.
