# v3.0.0-alpha.2：补做卡死、完全磁盘访问引导与更完整的进度

3.0.0 的第二个预览版，修复 alpha.1 试用中发现的问题。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 修复

- **未确认的翻译可以重新发送了**：alpha.1 中，翻译请求结果未确认时点「重新发送以上内容」会提示「这部分无需补做」，任务无法完成。现在只重新发送你确认的请求，已完成的部分直接使用之前的结果，不会重复发送；多批请求同时未确认时也能一次补完。卡片会写明这次还会顺带发送哪些内容（例如此前未能开始的摘要）。
- **截图查看器不再压住窗口按钮**：查看截图时，顶栏从标题栏下方开始，macOS 的红绿灯和 Windows、Linux 的窗口按钮都不再被遮住。
- **任务进度更完整**：AI 步骤显示发送和收到的 token 数，完成后仍保留；修复了摘要的 token 少算的问题；扫描画面时显示已找到的候选截图数；同时进行的步骤（如扫描画面和语音识别）各自显示进度。
- **运行中任务的进度会持续更新**，任务运行时阅读器不再反复重绘。
- **大字号下的设置页**：窗口较窄或字号较大时改为单列，分类用下拉选择，不再截断。
- 改名后阅读器标题随之更新；「移动到」在没有文件夹时可直接新建；模型准备失败会在任务卡片上提示并可重试；字幕轨列表不再重复显示英文原轨，机器翻译轨会标明。

## YouTube 登录：完全磁盘访问引导

macOS 27 不允许未授权的应用读取 Chrome、Safari 等浏览器的数据。现在设置 YouTube 登录时，应用会先检查，需要时用三步引导你完成授权：打开「系统设置 › 隐私与安全性 › 完全磁盘访问」，打开 course2md（可「在访达中显示 course2md」后拖入），然后重新打开应用。授权生效后会自动继续。从「下载」文件夹或磁盘镜像直接运行时，会先提示将 course2md 移到「应用程序」。CLI 会提示给所用的终端 App 授权。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui@alpha`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.2/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.2/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的其他文件 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.2/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

设置、笔记和模型缓存都会保留。在「设置 → 应用」确认版本 `3.0.0-alpha.2`；CLI 使用 `course2md --version` 确认。

## 验证范围

自动测试、三个平台的 CI，以及在隔离环境中用模拟服务器驱动真实应用的独立评审均已运行。付费请求的重新发送在 30 多种场景下验证过：已完成的请求不会重复发送，未确认的请求只在你确认后发送。完全磁盘访问引导中的系统设置、访达和重新打开应用无法自动测试，尚未在真机上验证；真实账号的登录与下载也尚未验证。

## English

**course2md 3.0.0-alpha.2** fixes what alpha.1 testing found. **Resending uncertain requests works:** a task with uncertain translation requests no longer refuses the resend with "nothing to repair"; only the requests you confirm are sent, finished ones are reused from their receipts, several uncertain batches finish in one go, and the card says what else the resend sends. **Screenshot viewer** no longer sits under the window buttons. **Task progress** shows tokens sent and received per AI step (kept after the step finishes), candidate screenshots during the scene scan, and a line for each step running at the same time; the summary's token count is fixed, and running progress keeps moving. Settings switch to one column at large text sizes; the reader heading follows a rename; failed model preparation shows on the card with a retry; YouTube's English captions appear once and machine translations are labelled.

**YouTube sign-in on macOS 27:** browsers' data needs Full Disk Access, so the app checks first and walks you through it: open System Settings › Privacy & Security › Full Disk Access, turn on course2md (Show course2md in Finder helps you add it), reopen the app. It continues on its own once access works, and asks you to move the app to Applications first when it runs from Downloads or a disk image. The CLI names the terminal app to allow.

**Install or upgrade:** `brew upgrade --cask course2md-gui@alpha` (or `brew install --cask mizorewww/tap/course2md-gui@alpha`), `brew install mizorewww/tap/course2md-alpha`, or the downloads above. Prereleases don't replace the stable release, and AUR skips them. The Full Disk Access flow's System Settings, Finder and relaunch steps, and real-account sign-in, have not been checked by hand yet. Please report any issues.
