# v3.0.0-alpha.5：Windows 安装程序，长笔记流畅缩放

3.0.0 的第五个预览版。Windows 有了安装程序；阅读器在长笔记上调整窗口大小不再卡顿；删除服务后任务不再卡住，工作台和任务页的界面也做了整理；不再读取 3.0 之前的记录。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## Windows 安装程序

- **新的安装程序** `course2md-desktop-windows-x64-setup.exe`：只为当前用户安装到 `%LOCALAPPDATA%\Programs\course2md`，不需要管理员权限；添加「开始」菜单快捷方式，可选桌面快捷方式；安装界面有简体中文、繁体中文、英文和日文。
- **原地升级**：之后的版本直接安装到同一位置。升级时如果 course2md 仍在运行，安装程序会先关闭它和它启动的工具（只关闭本应用安装目录里的程序）；进行中的任务可以继续。
- **卸载不删数据**：设置、已下载的模型和笔记库都会保留。
- 安装程序尚未签名，首次运行时 SmartScreen 会询问，选择「更多信息 → 仍要运行」。便携版 ZIP 继续提供。

## 阅读器

- **长笔记调整窗口大小不再卡顿**（#42）。之前每次改变宽度都会在同一帧重排整篇笔记，约 30 万字的笔记每帧要 0.2 秒以上；现在只立即重排屏幕上的部分，其余在之后几帧逐步完成，各种长度的笔记都在一帧（约 6 毫秒）内完成。调整大小后，阅读位置和跳转到的标题保持不变。

## 删除服务后任务不再卡住

- **删除 AI 或语音识别服务后**（或重置服务设置、从较旧的备份恢复），用到它的任务会显示「任务使用的服务已不在设置中，请调整后重试并选择服务」，并以「调整后重试」为主要操作；新的尝试改用当前默认服务。之前只能点「继续」，而「继续」会再次失败，「调整后重试」也会把已删除的服务带进新草稿。原任务保留它用过的服务版本，新尝试使用自己的工作文件夹，已付费的请求不会被重复发送。
- 草稿选中的服务被删除后会改用默认服务，并在卡片上写明。服务记录暂时无法读取时，不会清掉你的选择。

## 界面

- **工作台**：无法开始的原因显示为卡片内的一条提示，解决办法的按钮就在提示里，「开始转换」在此期间不可用；卡片的操作统一放在底部一行；处理选项与卡片连成一个整体；视频封面填满缩略图。
- **首页**：需要处理或已暂停的任务放在单独的「任务」区域，「最近的笔记」只显示笔记，同一条错误不再出现两次。
- **任务页**：「需要处理」只出现一次；原因以提示显示并带有对应操作；卡片以视频封面开头；只有一个任务时不显示「全部暂停/继续」。
- 因模型未下载而停止的任务不再提供会再次失败的「继续生成」；在设置中准备好模型后，等待它的任务会自动继续。
- 保存的错误信息按当前界面语言显示；「重新生成」按钮文字缩短，确认对话框仍说明会覆盖笔记；链接预览失败时只提供一个正确的操作；未填写笔记名称时可直接「填写名称」。

## 不再读取 3.0 之前的记录

- **2.x 的任务记录**不再读取。打开时会显示提示并写明文件位置，原文件不做任何改动。选择「备份并重建任务记录」会把它存档并开始新的记录；原记录中仍然存在、带有标识的笔记库会自动找回，其余会列出，需要在存储设置中重新添加。
- 笔记库中 2.x 留下的任务副本和 `events.jsonl` 之前的进度文件同样原样保留、不再读取。
- alpha.1 至 alpha.4 的数据不受影响。

## 命令行

- 命令行的转换与桌面应用走同一条任务流程。升级前中断的命令行任务会在原来的工作文件夹继续：已完成的请求不会重复付费，响应丢失的请求仍会被拦下。视频的上传者或时长在两次运行之间改变时，任务照常继续。
- `--json` 的 `done` 事件里 `out_dir` 和 `manifest` 总是绝对路径；「笔记已生成」一行也改为显示绝对路径。
- 明确指定已不再支持的模型（如 `--provider npu --asr-model qwen3-1.7b`）时会报错，不会自动改用其他模型。

## 其他

- README 开头新增各平台的下载按钮。
- 界面组件库更新到最新版本，界面外观不变。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui@alpha`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

## English

**course2md 3.0.0-alpha.5: a Windows installer, and smooth resizing on long notes.**

**Windows installer.** `course2md-desktop-windows-x64-setup.exe` installs course2md for your account only, with no administrator rights. It installs to `%LOCALAPPDATA%\Programs\course2md` and adds a Start menu shortcut (a desktop shortcut is optional), with setup in English, Simplified and Traditional Chinese, and Japanese.
- **Upgrades in place:** a later version installs into the same location. If course2md is still running, setup first closes it and the tools it started; only programs from its own install folder are closed.
- **Uninstalling keeps your data:** settings, downloaded models and notes stay.
- **Unsigned for now:** SmartScreen asks on first run (More info → Run anyway). The portable ZIP is still available.

**Reader.** Resizing the window on a long note no longer stalls (#42). Before, the whole note was laid out again on every width change, over 0.2 s per frame for about 300k characters. Now only what is on screen is laid out right away and the rest over the following frames, so each frame takes about 6 ms on any note. The reading position and a heading you jump to stay put.

**A deleted service no longer dead-ends a task.** After an AI or speech service is deleted (or the services settings are reset, or an older backup is recovered), a task that used it says the service is no longer in Settings and leads with Adjust and retry; the new attempt uses the current default service. Before, only Resume was offered, which failed again, and Adjust carried the deleted service into the new draft. The old task keeps its service version, the new attempt gets its own work folder, and paid requests are not sent twice. A draft whose service was deleted switches to the default and says so; an unreadable services record never clears your choice.

**Interface.** On the workbench, what blocks a draft is one notice inside the card with its fix, and Start is disabled meanwhile; the card's actions share one footer row, the options join the card, and covers fill their frame. Home lists tasks that need you in their own section, so Recent notes holds notes only and no error shows twice. The Tasks page names "Needs attention" once and shows each reason as a notice with its action. A task stopped for its model no longer offers a Continue that would fail, and preparing the model in Settings resumes it. Saved errors follow the current language.

**Records from before 3.0 are no longer read.** A 2.x task record is left exactly as it is, and the app shows where it is. "Back up and rebuild task records" archives it and starts a new record. Note libraries from the old record that still exist and carry their marker come back; the others are listed for you to add again. 2.x task copies in a library, and progress files from before `events.jsonl`, are left in place but no longer read. Data from alpha.1 to alpha.4 is unaffected.

**CLI:**
- Conversions run through the same task path as the desktop app.
- A command-line task interrupted before upgrading continues in its work folder. Finished requests are not paid for again, and a request whose answer was lost stays held. A changed uploader or duration does not stop it.
- In the `--json` `done` event, `out_dir` and `manifest` are always absolute, and so is the "Notes ready" line.
- An explicitly chosen model that is no longer supported is refused rather than replaced.

**Also:** download buttons for each platform at the top of the README, and the UI kit updated with no visible change.

**Install or upgrade:**
- `brew upgrade --cask course2md-gui@alpha`, or `brew install --cask mizorewww/tap/course2md-gui@alpha` for a first install.
- `brew install mizorewww/tap/course2md-alpha` for the standalone CLI.
- The downloads above.

Prereleases don't replace the stable release, and AUR skips them.

**Testing:**
- The Windows installer is installed, upgraded while running, and uninstalled on Windows CI for every change.
- The resize fix was measured in a macOS release build.
- The CLI change was checked against a real interrupted alpha.4 task.
- Not yet verified: installing on a real Windows PC, and logging in and downloading with real accounts.

Please report any issues.
