# v2.0.0-rc.17：更快更稳的界面、可靠的任务控制与全面校对的翻译

这是 **2.0 的第十七个候选发布版（RC17）**。本版来自一次全面的代码审查：修复了几处会影响笔记和设置的问题，让界面在大型笔记和长任务下更流畅，并校对了全部界面翻译。稳定版 Latest 保持不变。

## 相比 RC16

### 修复

- **删除正在处理的笔记**：笔记正在被任务写入新版本时，此前仍可移到废纸篓。现在会提示先等任务完成。
- **保存服务密钥不再卡住界面**：添加、发布或删除 AI / 语音服务时，钥匙串可能弹出授权框；这些操作改在后台进行，窗口不会冻结。
- **任务进度写盘不再阻塞界面**：笔记库位于外置盘或网络盘时，任务每进入一个阶段界面都会顿一下；启动时也不再逐个校验所有已完成任务的文件，窗口立即打开，校验在后台完成。
- **大字号下的阅读器工具栏**：125% 及以上字号打开查找时，「导出」按钮会超出窗口右边缘；现在笔记标题先收缩，查找框其次。
- **拖动滚动条后记住阅读位置**：此前只有滚轮和键盘滚动会保存位置。
- **只补摘要失败时不再生成重复版本**：补做摘要失败时，不再发布一个与原版只差失败记录的新版本，原笔记保持不变。
- **Apple 识别模型从镜像下载**：在中国大陆网络下改从镜像下载模型的过程更安全，暂停任务时会立即停止下载。

### 更流畅

- 截图视图只绘制可见的截图，几百张截图的笔记切到「截图」也不卡顿；查找高亮预先计算。
- 阅读时滚动、笔记库卡片和导出菜单不再每帧复制整份笔记。
- 输入时不再为每次按键新建线程；后台读写统一使用一个线程池。

### 翻译

- 全部英文、繁體中文和日本語界面文字经过校对，修正了约一千处机器翻译错误，例如截图数显示为「1 Zhang」、按钮小写、日文把「观看」译成「時計」、把「笔记」译成「音名」。繁體中文改用台湾惯用的软件用语。
- 导出的 Markdown 笔记和 HTML 笔记现在使用同一套标签翻译。

### 命令行

- `--json` 和 `run-task` 输出的 `error` 事件新增稳定的 `code` 字段（如 `invalid_arguments`、`invalid_configuration`、`missing_tool`、`authentication`），脚本无需解析提示文字。
- `course2md summarize` 与桌面应用走同一套补做流程。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.17/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.17/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.17/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。Homebrew 会安装这些依赖，Windows 桌面包已内置 aria2；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC16 或更早的 RC 升级可直接覆盖安装，保留配置、课程输出及模型缓存。已保存的任务记录和设置会照常读入，并在下次保存时改用新格式；进行中的任务可以继续。
- 已知限制：上述界面修复已在 macOS 上运行检查；Windows 与 Linux 版本只经过自动构建和测试。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.17`；CLI 使用 `--version` 确认。

## English

**2.0 RC17** comes from a full code review. A note being written by a running task can no longer be moved to the trash. Saving or deleting a service key no longer freezes the window while the keychain asks for permission, task progress no longer blocks the interface on slow or external library drives, and the window opens without first re-verifying every finished note. At 125% text and above, the reader's Export button stays inside the window. The reading position is kept after dragging the scrollbar, and a failed summary-only retry no longer publishes a duplicate version.

The screenshot view draws only visible screenshots, and reading, library cards and export menus no longer copy whole notes on every frame. Every English, Traditional Chinese and Japanese interface string was reviewed, correcting about a thousand machine-translation errors. `--json` and `run-task` error events now carry a stable `code` field.

Use the platform assets above or the independent Homebrew RC channels. The interface fixes were checked on macOS; the Windows and Linux builds were tested automatically only. Please report any issues.
