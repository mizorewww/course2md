# v3.0.0-alpha.7：千问语音识别，复制截图

3.0.0 的第七个预览版。新增千问语音识别服务（qwen3-asr-flash），截图可以右键复制，截图大图中的长文字可以完整阅读，右键菜单也能用键盘打开。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 千问语音识别

- **新的语音服务类型「千问语音识别（如 qwen3-asr-flash）」**（#61）：按千问 OpenAI 兼容接口 `/chat/completions` 的格式发送音频，可在桌面应用的「设置 → 服务与账号」里添加。地址填 `https://maas.qianwenaiapi.com/compatible-mode/v1`（阿里云百炼的工作空间地址同样以 `/compatible-mode/v1` 结尾），模型填 `qwen3-asr-flash`。
- 服务检查和实际转写使用同一种请求格式，检查通过就能转写。
- 音频会切成每段不超过约两分钟，符合千问每次请求的大小和时长限制。
- 地址或模型不对时，错误提示会指出可能的原因。在其他语音服务类型里填了千问的地址时，会建议改用这个类型，但不会替你更改。
- 命令行和配置文件使用 `mode = "qwen-chat"`，示例见 README。原有的「专用转写」和「音频对话」两种类型不变。

## 截图

- **右键复制**：在笔记中的截图、截图页的卡片和截图大图上右键，可以复制图片、复制图片路径，或在访达中显示。macOS 和 Windows 复制的是图片本身（PNG）；Linux 上只能复制文字，因此只提供复制路径和在文件管理器中显示。
- **长文字可以完整阅读**：截图大图下方的文字过长时，在宽窗口中改为放在图片旁边单独滚动，窄窗口中在图片下方滚动。之前只显示前几行，看起来像已经结束。
- 在截图大图中复制后，「已复制图片」的提示会显示在大图上方，不再被遮住。

## 键盘与界面

- **右键菜单可用键盘打开**：在截图、笔记库的卡片和列表行、文件夹、已保存的服务、存储位置和任务卡片上，按 Shift+F10 或菜单键即可打开对应的菜单。菜单出现在项目旁边，不会盖住它。
- 截图大图的 ⋮ 按钮再点一次会关闭菜单；它的提示文字不再挡住菜单。
- 截图卡片和配色卡片在键盘选中时会显示完整的焦点框。
- 界面组件库更新到 gpui-kit-material 0.1.2。

## English

**course2md 3.0.0-alpha.7: Qwen speech recognition, copying screenshots.**

**Qwen ASR (#61).** A new speech service type, "Qwen speech recognition (e.g. qwen3-asr-flash)", sends audio in the format Qwen documents for its OpenAI-compatible `/chat/completions` endpoint.
- **Setup:** use the address `https://maas.qianwenaiapi.com/compatible-mode/v1` and the model `qwen3-asr-flash`. Alibaba Cloud workspace addresses also end in `/compatible-mode/v1`.
- **Service check:** it sends the same request as transcription, so a passing check means transcription works.
- **Audio:** it is cut into pieces of about two minutes or less, within Qwen's per-request limits.
- **Hints:** errors point at the likely cause. A Qwen address entered under another speech type suggests this type, without changing it for you.
- **CLI and config:** `mode = "qwen-chat"`. The existing transcription and audio-chat types are unchanged.

**Screenshots.**
- Right-click a screenshot in a note, on the screenshots tab or in the viewer to copy the image, copy its path or show it in Finder. The image is copied as PNG on macOS and Windows; Linux offers the path and the file manager.
- Long text under a screenshot in the viewer is now readable in full. It sits in its own scrolling column beside the image in wide windows, and scrolls below it otherwise.
- "Image copied" now shows above the viewer.

**Keyboard and interface.**
- Shift+F10 or the Menu key opens the right-click menu on screenshots, library cards and rows, folders, saved services, storage locations and task cards. The menu opens beside the item instead of over it.
- The viewer's ⋮ closes its menu on a second press, and its tooltip no longer covers the menu.
- Screenshot and palette cards show their whole focus ring.
- The UI kit is gpui-kit-material 0.1.2.

**Install or upgrade:**
- `brew upgrade --cask course2md-gui@alpha`, or `brew install --cask mizorewww/tap/course2md-gui@alpha` for a first install.
- `brew install mizorewww/tap/course2md-alpha` for the standalone CLI.
- Or use the downloads above; Windows has an installer.

Prereleases don't replace the stable release, and AUR skips them.

**Testing so far:**
- The Qwen requests were checked field by field against a local fake server but not yet against a real Qwen account.
- Copying and keyboard menus were run and captured on macOS without touching the system clipboard. Windows is covered by automated tests and builds only.

Please report any issues.
