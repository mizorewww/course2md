# v3.0.2：修复 Windows 上 Bilibili 登录失败

3.0.2 是 3.0.1 的修复版。

## 修复

- **Windows 上 Bilibili 登录始终失败**：扫码、密码、短信三种方式都会立即提示「请检查网络后重试」。原因是访问 bilibili.com 时只信任程序内置的根证书列表，而 B 站证书链的根（旧版 GlobalSign Root CA）已不在其中，Windows 便在握手后断开连接。现在改用系统的根证书库，与浏览器和 curl 一致（#91）。这一修复同样覆盖账号检查和读取 B 站页面信息。

## 其他

- 笔记库卡片改用与阅读页一致的圆角，同一行的卡片标题、信息与底边对齐；笔记菜单按钮移到标题行，点菜单不会再打开笔记；「导入」按钮改为与其他操作一致的圆角样式。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。3.0.2 是正式版，Homebrew 与 AUR 的稳定通道都会更新。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui`
- 独立 CLI：`brew install mizorewww/tap/course2md`（升级用 `brew upgrade course2md`）
- Arch Linux（x86_64）：`yay -S course2md-gui-bin`（GUI）或 `yay -S course2md-bin`（CLI）

## English

**course2md 3.0.2: Bilibili login works on Windows again.** Every Bilibili login method failed at once on Windows with "check your network". Requests to bilibili.com trusted only a bundled root list, which no longer has the legacy GlobalSign Root CA that bilibili's chain ends in, so Windows dropped the connection right after the handshake. They now use the system root store, like browsers and curl (#91); account checks and Bilibili page metadata are fixed too. Note library cards use the reader tiles' corners and line up across a row, the note menu no longer opens the note, and the Import button takes the same pill shape as the other library actions.

**Install:** `brew upgrade --cask course2md-gui` (Apple Silicon), `brew install mizorewww/tap/course2md` for the CLI, `yay -S course2md-gui-bin` or `yay -S course2md-bin` on Arch x86_64, or use the downloads in the table above. The Windows installer is unsigned, so SmartScreen asks first (**More info → Run anyway**). Settings, model caches and libraries are kept.
