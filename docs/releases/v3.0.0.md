# v3.0.0：一个视频一个任务、界面缩放滑块，3.0 正式发布

3.0.0 是 3.0 的正式版，取代 2.0.1 成为 Latest。经过 10 个预览版的试用，本版包含 3.0.0-alpha.10 的全部改动，并新增 Bilibili 视频的 BV 号 / AV 号导入。

## 升级前请了解

- **任务列表会被整理并变短**：首次打开时旧任务记录自动转换。同一视频有多条记录时只保留最新一条；已取消且没有笔记的任务被移除；部分完成、需要处理、需要确认的任务都变为「需要处理」。笔记本身不受影响。任务记录不再写入笔记库文件夹，关联已有笔记库不会再带入它的任务。
- **中断的 AI 请求会自动重发**：以前发出后没有确认结果的请求（程序退出、断线、服务 5xx）会让任务停在「需要确认」，等你选择「重新发送」。现在它们在下次运行时直接重发，可能产生额外费用；已完成的回答仍会复用，不重复收费。
- **重跑结果会替换现有笔记**：重新生成或重试后，笔记以新结果为准；唯一例外是新摘要失败时保留原来的摘要。
- **替换笔记时留下的旧副本会自动删除**：中断的替换会恢复最新的一份，其余 `old-*` 副本删除，不再提示手动处理。
- **命令行 `--json` / `run-task` 有不兼容变化**，见下文。

## 相比 3.0.0-alpha.10 的变化

- **Bilibili 视频可以用 BV 号或 AV 号导入**：主页输入框接受 `BV…` 或 `av…` 编号，与链接一样先预览再转换；占位提示同步更新。
- 界面组件库更新到 `material-v0.2.0`，依赖项同步更新。

## 任务：一个视频一个任务

- 任务只有五种状态：等待处理、正在生成笔记、已暂停、需要处理、笔记已生成。不再有「已取消」「部分完成」「需要确认」「正在暂停」。
- 每个笔记库里的每个视频只有一个任务。再次转换、重试和重新生成都更新原来的卡片，不再生成「后续任务」或「重新处理任务」；已在等待或处理中的视频不会重复加入。
- 操作：「继续」恢复暂停的任务；「重试」复用已完成的部分，按钮会写明要补做什么，例如「重试未完成的校对部分」；「重新生成」丢弃缓存从头开始，会重新发送 AI 请求。另有「全部暂停」「全部继续」「取消任务」「移除任务记录」。
- 取消任务就是移除它，已发布的笔记不会被动到。
- 「清空已完成」只清除任务记录和对应的工作缓存，生成的笔记不会被删除。
- 任务日志使用等宽字体，可以「复制日志」。

## 界面和设置

- 「界面缩放」滑块，75%–200%，每格 5%，拖动时显示实时预览，松开后应用，可「恢复 100%」，也可以用方向键调整。
- 设置修改后自动生效，不再需要「应用」按钮。
- 首次设置时输入的 API Key 在点「继续」后会被保存；服务卡片里新增「检查配置」。
- 粘贴多个视频链接时可以勾选多个一起转换；其中已有笔记的会先询问是否替换。
- 阅读页新增「复制笔记」，复制 Markdown 原文。

## 视频和字幕

- 直接读取更多字幕格式：YouTube json3 / srv1–3、TTML、Bilibili bcc、ASS、LRC。
- 系统里安装了比内置更新的 yt-dlp 时优先使用它；deno、node 或 bun 会明确传给 yt-dlp，从 Finder 打开的 macOS 应用也能找到。
- 读不到浏览器 Cookie（例如没有授予「完全磁盘访问权限」）时，公开视频和字幕照常读取；只有 YouTube 确实要求登录时才提示授权。

## 命令行

- `--translate` 和配置中的翻译目标接受任意语言代码或名称（如 `pt`、`Italian`）；简体和繁体中文是不同目标。
- 配置文件中有未知的键时不再无法读取。`--gpu-layers` 接受 0–999。
- 云端语音识别失败时显示服务给出的原因（去掉密钥）。
- **`--json` / `run-task` 不兼容变化**：错误代码 `note_kept`、`note_recovery_blocked`、`note_copies_kept` 已移除，`error` 事件不再有 `parts` 和 `path` 字段；新的运行不再产生 `uncertain`。依赖这些的脚本需要更新。

## 从源码构建

- macOS 上 Xcode 的 Metal 工具链版本不匹配时，改用另一种方式编译 Metal 着色器，不再产生 CoreML 识别不可用的构建。`--app-only` 本地构建使用开发者证书签名，重新构建后保留 macOS 隐私权限。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。3.0.0 是正式版，Homebrew 与 AUR 的稳定通道都会更新。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui`
- 独立 CLI：`brew install mizorewww/tap/course2md`（升级用 `brew upgrade course2md`）
- Arch Linux（x86_64）：`yay -S course2md-gui-bin`（GUI）或 `yay -S course2md-bin`（CLI）

## English

**course2md 3.0.0: one task per video, no more "Needs confirmation" hangs, a UI scale slider, and Bilibili BV / AV IDs.** This is the stable release of 3.0. It contains everything in 3.0.0-alpha.10 and adds importing Bilibili videos by BV or AV ID from the Home page.

**Before you upgrade.** The task list is migrated on first launch and gets shorter. Unconfirmed AI requests are sent again on the next run, which may cost money; finished replies are reused. A rerun's result replaces the saved note. The `--json` / `run-task` breaking changes are listed in the Chinese notes above.

**Install:** `brew install --cask mizorewww/tap/course2md-gui` (Apple Silicon), `brew install mizorewww/tap/course2md` for the CLI, `yay -S course2md-gui-bin` or `yay -S course2md-bin` on Arch x86_64, or use the downloads in the table above. The Windows installer is unsigned, so SmartScreen asks first (**More info → Run anyway**).
