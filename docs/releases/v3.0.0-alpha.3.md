# v3.0.0-alpha.3：每个视频一份笔记（草稿）

> 草稿：发布前补全修复列表、安装表和验证范围。

## 每个视频一份笔记

- **不再保留笔记的多个版本。** 每个视频只有一份笔记。重新生成、补做和重试都直接更新这份笔记；工作台上的「重新生成（覆盖当前笔记）」会先确认。新的处理失败时，原笔记保持不变；新结果在尝试过的任何部分（如因 AI 服务不可用而缺少摘要）不如原笔记时，同样保留原笔记并说明原因。原笔记已有的导出会按新内容重新生成。处理期间阅读器照常显示原笔记，完成后在原位置刷新。
- **手动改过的文件会保留。** 被覆盖的笔记里你改过的文件（如 `course.md`）会以 `.edited` 为名（如 `course.edited.md`）放在新笔记旁，任务卡片会写明。
- **升级时整理旧笔记库。** 第一次打开时，每个视频只保留当前版本（只要正文可读，改过的文件原样保留；否则取最新的可读版本），其他版本删除；阅读位置和导出随之保留。之后会提示一次。
- **降级注意：** 整理后的笔记库用旧版应用（alpha.2 及更早）打开会显示为空。请不要在升级后再换回旧版。

## 命令行

- `--json` 的 `Done` 事件不再有 `version_id`；`out_dir` 是笔记文件夹本身；新增 `kept_edits`，列出另存为 `.edited` 的文件（相对于笔记）。
- 笔记保存在输出目录的 `平台/ID/` 下，处理中的数据放在旁边的 `.course2md/`。`course2md summarize` 直接为这份笔记补上摘要。

## English

**One note per video.** A video now has a single note: regenerating, filling in and retrying update it in place, and the workbench asks before “Regenerate (replaces the current note)”. If the new run fails, or does less than the note in any part it tried (a summary missing because the AI service was unreachable), the note stays as it was and the task says why; exports the note had are made again from the new content; the reader keeps showing it while the task runs and reloads in place when it finishes. Files you edited by hand are kept beside the new note under an `.edited` name, and the task card says so. On first launch, each video keeps its current version whenever its text is readable, hand-edited files included (otherwise the newest readable one), and the other versions are deleted; you are told once. **Downgrading:** older apps (alpha.2 and earlier) show the migrated library as empty. **CLI:** the `--json` `Done` event no longer has `version_id`, its `out_dir` is the note folder, and it adds `kept_edits`.
