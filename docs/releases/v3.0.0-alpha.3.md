# v3.0.0-alpha.3：每个视频一份笔记

3.0.0 的第三个预览版。笔记不再有多个版本：重新生成、补做和重试都直接更新同一份笔记。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 每个视频一份笔记

- **不再保留笔记的多个版本。** 每个视频只有一份笔记。重新生成、补做和重试都直接更新这份笔记；工作台上的「重新生成（覆盖当前笔记）」会先确认。处理期间阅读器照常显示原笔记，完成后在原位置刷新，回到原来的位置。
- **不会因为失败丢掉原笔记。** 新的处理失败、被中断或电脑意外关机时，原笔记保持不变。新结果在尝试过的任何部分不如原笔记时（例如 AI 服务不可用导致缺少摘要），同样保留原笔记，并写明是哪些部分。原笔记已有的导出会按新内容重新生成。
- **手动改过的文件会保留。** 被覆盖的笔记里你改过的文件（如 `course.md`）会以 `.edited` 为名（如 `course.edited.md`）放在新笔记旁；你自己放进笔记文件夹的文件也会保留。任务卡片会写明。
- **同一份笔记一次只处理一个任务。** 再为同一个视频开始任务时，会打开已有的任务。
- **升级时整理旧笔记库。** 第一次打开时，每个视频只保留当前版本（只要正文可读，改过的文件原样保留；否则取最新的可读版本），其他版本删除；阅读位置和导出随之保留。笔记库会提示一次。少数无法自动判断的情况会把副本留在笔记旁，并在笔记库里说明需要你查看的文件夹。
- **降级注意：** 整理后的笔记库用旧版应用（alpha.2 及更早）打开会显示为空。请不要在升级后再换回旧版。

## 其他修复

- **YouTube 播放列表中的视频**：「从此处观看」和笔记中的时间链接保留播放列表，可以正常观看（#32）。「稍后观看」「喜欢的视频」等个人列表不写入链接。命令行处理 `watch?v=…&list=…` 时处理这个视频，不再提示链接包含多个视频。修复前生成的笔记需要重新生成才有播放列表。
- **完全磁盘访问引导**：切换步骤时对话框回到顶部；「仍然尝试连接」失败时在对话框内说明；需要先把应用移到「应用程序」时不再显示步骤；从外接磁盘运行时的说明更准确。

## 命令行

- `--json` 的 `Done` 事件不再有 `version_id`；`out_dir` 是笔记文件夹本身；新增 `kept_edits`，列出另存为 `.edited` 的文件（相对于笔记）。依赖 `version_id` 的脚本需要调整。
- 新的错误代码：`note_kept`（新结果不如原笔记，原笔记已保留）、`note_busy`（这份笔记正被另一个任务处理）、`note_recovery_blocked` 和 `note_copies_kept`（需要你查看笔记旁的副本，附带文件夹路径）。
- 笔记保存在输出目录的 `平台/ID/` 下，处理中的数据放在旁边的 `.course2md/`。`course2md summarize` 直接为这份笔记补上摘要。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui@alpha`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.3/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.3/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的其他文件 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.3/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

设置和模型缓存会保留；笔记库会按上文整理。在「设置 → 应用」确认版本 `3.0.0-alpha.3`；CLI 使用 `course2md --version` 确认。

## 验证范围

覆盖笔记的过程经过六轮独立的对抗性评审：在每一步强制中断、磁盘写满、文件被锁定、多个任务同时写入、链接到其他磁盘、与 alpha.2 同时运行等情况下，笔记都能恢复，不会丢失；从 alpha.2 继续的任务不会重复发送已付费的请求。Windows 上文件被其他程序占用的情况只经过代码检查；新界面在 Windows 和 Linux 上只经过自动测试；真实账号的登录与下载尚未验证。

## English

**course2md 3.0.0-alpha.3: one note per video.** A video now has a single note: regenerating, filling in and retrying update it in place, and the workbench asks before “Regenerate (replaces the current note)”. If the new run fails, is interrupted, or does less than the note in any part it tried (a summary missing because the AI service was unreachable), the note stays as it was and the task says why; exports the note had are made again from the new content; the reader keeps showing the note while the task runs and reloads in place when it finishes. Files you edited by hand are kept beside the new note under an `.edited` name, files you added are kept, and the task card says so. One task at a time works on a note. On first launch each video keeps its current version whenever its text is readable, hand-edited files included (otherwise the newest readable one), and the other versions are deleted; the library tells you once, and names any folder that needs a look. **Downgrading:** older apps (alpha.2 and earlier) show the migrated library as empty.

**Also:** a YouTube video opened from a playlist keeps the playlist in its watch links (#32; personal lists such as Watch later are left out; notes made before need regenerating). The Full Disk Access guide scrolls to the top on each step, shows a refused try in the dialog, and words the move-to-Applications case better.

**CLI:** the `--json` `Done` event no longer has `version_id`, its `out_dir` is the note folder, and it adds `kept_edits`. New error codes: `note_kept`, `note_busy`, `note_recovery_blocked`, `note_copies_kept`.

**Install or upgrade:** `brew upgrade --cask course2md-gui@alpha` (or `brew install --cask mizorewww/tap/course2md-gui@alpha`), `brew install mizorewww/tap/course2md-alpha`, or the downloads above. Prereleases don't replace the stable release, and AUR skips them. Overwriting notes went through six adversarial reviews (forced crashes at every step, full disks, locked files, concurrent writers, linked notes, alpha.2 running alongside) with no note lost and no paid request sent twice. Please report any issues.
