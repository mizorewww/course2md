# v3.0.0-alpha.1：全新的桌面界面、账号登录与更稳的字幕

3.0.0 的第一个预览版。桌面应用改用 Material 3 界面重新构建，新增 B 站账号密码和短信登录、YouTube 浏览器登录，并修复了在线字幕的若干问题。这是 alpha 版：验收尚未全部完成，请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 桌面界面

- **Material 3 界面**：页面、对话框、菜单和动效统一按 Material 3 重做，保留了原有的彩色图标、大圆角链接框和多种配色。
- **下拉框、列表和配色选择**：选择类设置统一为下拉框；资料库侧栏、目录和设置分类用胶囊选中样式；配色选择改为四列预览，选中项有勾选标记。
- **阅读器**：摘要恢复为独立面板；章节时间和「从此处观看」合为一个按钮；截图显示时间并可放大。
- **切换语言立即生效**，不需要重启。

## 登录

- **B 站**：除扫码外，支持账号密码登录和短信登录；人机验证在浏览器中打开的本机页面里完成，风险登录时会要求验证手机。密码和验证码不保存、不写入日志。
- **YouTube**：使用浏览器的登录状态（Chrome、Safari、Firefox 等），不需要输入 Google 密码。macOS 27 会阻止读取 Chrome 等浏览器的资料，这时应用会提示在「系统设置 › 隐私与安全性 › 完全磁盘访问」中允许 course2md（CLI 为所用的终端），并提供打开设置的按钮。
- **登录后下载更稳**：B 站偶尔中断连接时会自动重试；下载失败时先显示 yt-dlp 给出的原因。

## 字幕与识别

- **YouTube 不再优先选机器翻译字幕**（#25）：原语言字幕优先于机器翻译；选中的字幕轨读取失败（例如 429 限流）时，依次改读下一条。
- **YouTube 滚动自动字幕**（#26）：每句只出现一次，开头和停顿后的句子时间正确，截图对齐不再错位。
- **在线字幕按界面语言选择**，桌面预览和任务选择同一条字幕轨。
- **下载语音模型前先询问**：桌面任务需要模型时停下并提供「下载并准备模型」，准备好后任务自动继续。CLI 在终端中询问 `[y/N]`；脚本和 `--json` 中不再静默下载，可用 `--download-models` 或 `COURSE2MD_DOWNLOAD_MODELS=1` 恢复旧行为。

## 任务与付费请求

- 从 2.0.1 升级后继续的任务，已完成的校对、摘要、翻译和识别请求不会重复发送。
- 应用在请求进行中被关闭、后台进程仍在运行时，重新打开不再卡住，任务会在后台进程结束后继续。
- 笔记由更新版本的应用生成时，在发送任何请求前就提示更新应用。
- 连接不上的服务测试显示「尚未发送」，不再提示可能已扣费。

## 其他

- 应用和模型下载支持 `HTTPS_PROXY` / `ALL_PROXY` / `NO_PROXY`。
- `RUST_LOG=trace` 不再输出 API 密钥。
- 引擎拆分为多个 crate，供开发者参考 [`docs/CRATES.md`](https://github.com/mizorewww/course2md/blob/v3.0.0-alpha.1/docs/CRATES.md)。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.1/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.1/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的其他文件 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.1/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

设置、笔记和模型缓存都会保留。启动后在「设置 → 应用」确认版本 `3.0.0-alpha.1`；CLI 使用 `course2md --version` 确认。

## 验证范围

自动测试、三个平台的 CI，以及在隔离环境中用模拟服务器驱动真实应用的两轮独立验收均已运行；第三轮验收进行中。B 站账号登录后的下载、账号密码与短信登录、YouTube 登录尚未用真实账号验证；Windows 和 Linux 上的新界面只经过自动测试。

## English

**course2md 3.0.0-alpha.1** is the first 3.0 preview. The desktop app is rebuilt on a Material 3 interface, keeping its coloured icons, large-radius link field and palettes; choices are dropdowns, sidebars use pill selection, and language changes apply at once. **Sign-in:** Bilibili adds password and SMS login, with the human check in a local page in your browser; YouTube uses your browser's session. On macOS 27, reading Chrome's data needs Full Disk Access for course2md (or your terminal for the CLI), and the app says so. **Subtitles:** YouTube's machine translations no longer outrank the original track, and an unreadable track falls back to the next (#25); rolling auto-captions appear once with correct timing (#26). **Models:** speech models are downloaded only after you agree; the CLI asks `[y/N]` in a terminal and refuses in scripts unless `--download-models` is given. **Tasks:** continuing a 2.0.1 task resends no finished paid request; relaunching while an old worker runs no longer hangs. Proxies (`HTTPS_PROXY`, `ALL_PROXY`, `NO_PROXY`) are honoured, and trace logs no longer print API keys.

**Install:** `brew install --cask mizorewww/tap/course2md-gui@alpha`, `brew install mizorewww/tap/course2md-alpha`, or the downloads above. Prereleases don't replace the stable release, and AUR skips them. Real-account sign-in and download, and the new interface on Windows and Linux, have not been checked by hand yet. Please report any issues.
