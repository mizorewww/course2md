# v3.0.0-alpha.4：笔记库排序

3.0.0 的第四个预览版。笔记库可以按规则排序或手动调整顺序，并修复了 alpha.3 之后发现的一些问题。请先在不重要的视频上试用，遇到问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## 笔记库排序

- **六种排序方式**：添加时间、标题、视频发布时间、最近阅读、时长和手动（#33）。除手动外都可以切换升序或降序。按标题排序时「第 2 集」排在「第 10 集」之前。按发布时间排序时，卡片显示视频的发布日期。
- **每个位置各自记住排序**：「全部笔记」「未分类」和每个文件夹分别保存自己的排序方式和手动顺序。移动、重命名笔记或移动笔记库后，顺序保留。
- **手动排序**：在卡片视图和列表视图中拖动笔记，或用 Option + 方向键移动当前笔记；笔记菜单里也有「前移」「后移」。在其他规则下拖动时，会以当前看到的顺序为起点切换到手动排序，并提示一次。新加入的笔记排在最后。搜索时不能调整顺序。
- 排序信息保存在笔记库里的 `.course2md-order.json`，「全部笔记」的排序保存在应用自己的数据里，不写进笔记文件夹。

## 其他改进与修复

- **任务进度**：同时进行的步骤分别显示编号（如「第 4 步 · 扫描画面；第 6 步 · 语音转写」），任务卡片的高度不再随步骤变化；画面、截图和文字段数加上千位分隔符；上传和下载的 token 按步骤计数，较晚返回的结果不会重复计入。
- **被副本上限挡住的笔记**在笔记库中显示「需要处理」，不再显示「正在处理」。副本上限的提示说明：笔记旁保留 3 份及以上副本时，新的任务会一直停止。
- **旧版应用又保存了笔记**：升级后如果又用 alpha.2 保存过同一份笔记，较新的结果会成为这份笔记，之前的笔记作为副本保留在旁边，并提示一次。旧版应用仍在写入时，新版会等它完成，不会在中途覆盖。
- **笔记保存锁**：无法打开的锁文件不再被误报为「旧版应用正在保存」；没有权限时提示检查文件夹权限。
- **模型下载**：断点续传前核对文件版本，不会把两个版本的数据拼在一起；下载不完整时说明预期和实际收到的大小；下载进行中查看模型状态不再报「找不到文件」。
- **英文界面**：数量为一时使用单数（如「1 screenshot」）。
- 两处提示中的按钮更醒目。
- 界面组件库更新到最新版本；中文标签宽度略有变化（约 1pt），与 macOS 的文字排版一致。

## 命令行

- 只写文件名的本地视频（如 `course2md lecture.mp4`）现在能找到当前目录下的同名字幕。
- 新的错误提示：下载不完整（附预期和实际大小）。

## 开发者

- course2md 拆出的三个库已发布到 crates.io，各自带有命令行工具（`--features cli`）：[subtitle-parse](https://crates.io/crates/subtitle-parse)（字幕解析与清理）、[slide-detect](https://crates.io/crates/slide-detect)（提取讲座视频中的幻灯片）、[mirror-fetch](https://crates.io/crates/mirror-fetch)（原 model-fetch，可断点续传、带校验的多镜像下载）。
- 构建工具链为 Rust 1.98.1。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。预览版不会替换正式版，AUR 不发布预览版。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui@alpha`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui@alpha`
- 独立 CLI：`brew install mizorewww/tap/course2md-alpha`

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.4/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.4/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的其他文件 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v3.0.0-alpha.4/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

设置、模型缓存和笔记库都会保留。在「设置 → 应用」确认版本 `3.0.0-alpha.4`；CLI 使用 `course2md --version` 确认。

## 验证范围

排序和本版的修复都经过三轮独立评审，覆盖排序记录损坏、多个窗口同时写入、笔记被复制、扫描未完成时不丢失排序信息等情况；与旧版应用同时写入笔记的处理在每一步强制中断和出错的情况下都不会丢失笔记。界面在 macOS 上实际运行并截图核对；Windows 和 Linux 上只经过自动测试；真实输入法输入和真实账号的登录与下载尚未验证。

## English

**course2md 3.0.0-alpha.4: sorting the library.**

**Sorting.** Sort a library place by date added, title (episode 2 before episode 10), publish date, last read, duration, or by hand; every rule but manual goes either way (#33). "All notes", "Unfiled" and each folder keep their own sort and manual order, which survive moving or renaming a note or the library. Reorder by dragging in card or list view, with Option + arrow keys, or with Move earlier / Move later in a note's menu; a drag under another rule switches to manual order starting from what is shown. New notes go last. Sorting lives in the library's `.course2md-order.json`, and "All notes" in the app's own data, never in note folders.

**Also:**
- **Progress:** steps running together show their numbers, and the task card keeps its height. Counts get thousands separators, and tokens are counted per step, so a late answer is counted once.
- **Copy limit:** a note stopped at the copy limit reads "Needs attention", not "Processing".
- **Older app:** if alpha.2 saved a note again after upgrading, its newer result becomes the note and the previous one is kept beside it. While an older app is still writing, this one waits.
- **Lock errors:** a lock that can't be opened is no longer reported as an older app saving.
- **Model downloads:** a download checks the file's version before resuming, so two versions are never joined. An incomplete download says which size was expected. Inspecting models during a download no longer fails.
- **English UI:** counts of one are singular.
- **Kit update:** the UI kit is updated, and Chinese labels measure about 1pt narrower, matching macOS.

**CLI:** a local video given as a bare file name finds its subtitles in the current directory.

**Developers:** the three libraries split out of course2md are on crates.io with command-line tools (`--features cli`): [subtitle-parse](https://crates.io/crates/subtitle-parse), [slide-detect](https://crates.io/crates/slide-detect) and [mirror-fetch](https://crates.io/crates/mirror-fetch) (formerly model-fetch). The toolchain is Rust 1.98.1.

**Install or upgrade:**
- `brew upgrade --cask course2md-gui@alpha`, or `brew install --cask mizorewww/tap/course2md-gui@alpha` for a first install.
- `brew install mizorewww/tap/course2md-alpha` for the standalone CLI.
- Or the downloads above.

Prereleases don't replace the stable release, and AUR skips them.

**Testing so far:** sorting and these fixes each went through three independent reviews. The UI was run and captured on macOS; Windows and Linux are covered by automated tests only. Please report any issues.
