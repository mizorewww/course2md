# v2.0.0-rc.18：Material 3 全新界面、可用的截图浏览与清楚的下载进度

这是 **2.0 的第十八个候选发布版（RC18）**。本版重新设计了整个桌面应用，修复了笔记截图页无法使用的问题，并让模型下载显示速度和剩余时间。稳定版 Latest 保持不变。

## 相比 RC17

### 全新界面

- 主页、笔记库、任务、阅读器、设置、首次使用引导和各类对话框统一采用 Material 3 设计：同一套颜色、按钮、图标（Lucide 线性图标）、进度条和动效，深色主题的层次更清楚。
- **处理选项始终对应一个视频**：选项面板紧贴视频预览卡片，标题栏就是唯一的展开/收起按钮，状态会被记住。任务开始后，正在处理的任务占据卡片位置并附上提交时的设置，可随时「设置下一个视频」或「取消任务」。修复了从任务页回到主页后选项面板消失的问题。
- 任务页分为正在处理、已暂停和已完成，运行中的任务只显示一个状态。
- 窗口较窄或字号较大时，顶栏、阅读器标题栏、账号按钮、选项按钮和页面标题会依次收起或换行，不再被截断；链接输入框的提示文字会换成能完整显示的短句。

### 截图

- 「截图」页可正常浏览：截图按显示尺寸解码并有内存上限，离开笔记后会释放，反复打开笔记内存不再增长。
- 查看大图时可拖动、双指缩放和逐张翻看；目录跟随正在阅读的章节。
- 无法读取的截图在卡片、正文和查看器中显示同样的提示。

### 模型下载

- 所有模型下载（包括 Apple 语音识别模型）显示已下载大小、速度和预计剩余时间。
- Apple 模型按 8 MB 分块到达，分块之间会显示上一块到达的时间；只有 5 分钟没有新数据才提示停滞。
- 断点续传时，已在磁盘上的部分不再计入速度，速度和剩余时间不再虚高。

### 文字与翻译

- 用时和剩余时间按界面语言显示（如「用时 1 分 05 秒」），数字与单位、标签与数值不会被拆到两行；中文和日文的数量使用「万」「亿」。
- 中日文换行时，句末标点不会出现在行首。
- 英文、繁體中文和日本語的多处界面文字统一了用语。

### 安装

- `just install` 会记住已应用的补丁，补丁更新后可以直接重新安装；在 Windows 上也按 UTF-8 读取补丁。

## 下载桌面应用

GUI 包含同版本 CLI 引擎，无需另装 CLI。

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.18/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.18/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0-rc.18/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。Homebrew 会安装这些依赖，Windows 桌面包已内置 aria2；手动安装请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

## Homebrew RC 通道

首次安装：

```sh
brew update
brew install --cask mizorewww/tap/course2md-gui@rc
```

已有稳定版或旧 RC 的用户，先退出应用，再卸载原 cask（`course2md-gui` 或旧 RC），然后安装 RC cask。卸载时不要加 `--zap`，以保留用户数据。

后续更新使用 `brew upgrade --cask course2md-gui@rc`。独立 CLI 的 RC 通道：

```sh
brew install mizorewww/tap/course2md-rc
"$(brew --prefix course2md-rc)/bin/course2md" --version
```

独立 CLI 附件覆盖 macOS ARM64/x86_64、Linux ARM64/x86_64 和 Windows x64。手动安装 Apple Silicon CLI 时，还需下载本页 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 并放在 CLI 同一目录；Unix 可执行文件需赋予执行权限。

## 升级与验证范围

- 从 RC17 或更早的 RC 升级可直接覆盖安装，保留配置、课程输出及模型缓存。
- 已知限制：新界面已在 macOS 上运行检查；Windows 与 Linux 版本只经过自动构建和测试。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

启动后在“设置 → 应用”确认版本 `2.0.0-rc.18`；CLI 使用 `--version` 确认。

## English

**2.0 RC18** redesigns the whole desktop app on Material 3: home, library, tasks, reader, settings, onboarding and dialogs share one set of colors, controls, Lucide outline icons, progress and motion. Processing options always belong to one video, with a single show/hide header that is remembered; a running task takes the video card's place with its submitted options, and the options panel no longer disappears after visiting a task. Narrow windows and large text collapse or wrap the app bar, reader title bar and buttons instead of clipping them.

The note's Screenshots tab works again: screenshots decode at their drawn size in a bounded cache that is released when the reader closes, the viewer supports drag, pinch and stepping, and unreadable screenshots look the same everywhere. Every model download, including Apple speech models, shows size, speed and time left; resumed downloads no longer inflate the speed. Durations and counts follow the interface language, and CJK lines no longer start with closing punctuation.

Use the platform assets above or the independent Homebrew RC channels. The new interface was checked on macOS; the Windows and Linux builds were tested automatically only. Please report any issues.
