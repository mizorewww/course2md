# v2.0.0：全新桌面应用、可靠的后台任务、笔记库文件夹与四语言界面

这是 **course2md 2.0 的首个正式版**，取代 1.7.0 成为 Latest。2.0 重做了桌面应用：从添加视频、后台处理到整理和阅读笔记，每一步都更清楚、更可靠。经过 alpha 和 17 个候选发布版的试用，本版同时汇总了 RC18 的全部改进。

## 相比 1.7 的主要变化

### 桌面应用

- **全新界面**：主页、笔记库、任务、阅读器、设置和首次引导统一采用 Material 3 设计，提供 10 套主题、界面文字大小和减少动态效果选项。窗口较窄或字号较大时，顶栏和按钮会收起或换行，不会被截断。
- **四种界面语言**：英文、简体中文、繁體中文和日本語，可在「设置 → 外观 → 界面语言」即时切换；命令行跟随系统语言，也可用 `--lang` 指定。
- **先预览再转换**：在主页粘贴链接或拖入本地视频，确认预览和处理选项后点击「开始转换」。Bilibili 分集（多 P）和播放列表可以多选，一次加入队列。
- **后台任务**：任务可以暂停、继续、拖动调整顺序，退出应用后可以接着处理。部分失败时可以先阅读已完成的内容，再只补做失败的部分；重新处理会保留旧版本笔记。
- **笔记库**：文件夹树、可以嵌套的文件夹、拖放和「移动到」整理，搜索包含所有子文件夹；可以有多个笔记库位置，笔记可删除到废纸篓（Windows 为回收站）。
- **阅读器**：摘要卡片、截图与正文交替的章节、目录、查找、截图视图和可拖动缩放的大图查看器，记住每篇笔记的阅读位置；可导出带图片的 HTML。
- **首次引导**：四步选择识别方式、连接 AI 服务和 Bilibili 账号、准备识别模型；可跳过，也可从设置重新开始。
- **服务密钥**保存在系统钥匙串（Windows 凭据管理器、Linux Secret Service），无法使用时退回仅本人可读的文件。

### 笔记内容

- **数学公式**：AI 校对和摘要会把公式（包括口述的公式）写成 LaTeX，在阅读器和 HTML 导出中排版显示。
- **双语笔记**：AI 校对后在每段下方附上译文，支持简体中文、繁體中文、English、日本語、한국어、Français、Deutsch、Español；可在设置中统一选择，也可按任务单独选择。命令行使用 `--translate <LANG>`。
- **更多 AI 服务**：除 OpenAI 兼容服务外，可使用本机 Ollama 或 ChatGPT 订阅（导入 Codex 登录）。请求中断会被及时发现，不按次计费的服务自动重发。

### 模型下载

- 中国大陆网络下自动改用 ModelScope 或 hf-mirror.com，其他地区优先 Hugging Face；支持断点续传和 SHA-256 校验，装有 aria2 时多线程下载。
- 所有模型下载显示已下载大小、速度和预计剩余时间。

### 命令行

- 新增 `--login ollama`、`--login codex`、`--summarize` / `--no-summarize`、`--translate` 和 `--lang`。
- `course2md doctor` 显示实际使用的 yt-dlp 路径；install.sh 和桌面安装包附带独立的 yt-dlp。
- `--json` 和 `run-task` 的错误事件带有稳定的 `code` 字段，方便脚本判断。

## 相比 RC17

- RC18 的全部改进：Material 3 新界面、每个视频对应自己的处理选项、可用的「截图」页和大图查看器、清楚的模型下载进度、按界面语言显示的用时与数量，以及中日文行首不再出现句末标点。详见 [RC18 说明](https://github.com/mizorewww/course2md/blob/v2.0.0/docs/releases/v2.0.0-rc.18.md)。
- **阅读器可以选中和复制文字**：复制公式时得到原始 LaTeX。
- **放大截图旁的长段文字可以完整阅读**，不再被截断。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI；独立 CLI 不会安装桌面应用。

**包管理器**（会一并安装 ffmpeg、yt-dlp 和 aria2）：

- macOS Apple Silicon：`brew install --cask mizorewww/tap/course2md-gui`
- Arch Linux / CachyOS x86_64：`yay -S course2md-gui-bin`
- 独立 CLI：`brew install mizorewww/tap/course2md` 或 `yay -S course2md-bin`

**手动下载桌面应用：**

| 平台 | 安装包 | 使用方式 |
| --- | --- | --- |
| macOS Apple Silicon，macOS 15+ | [DMG](https://github.com/mizorewww/course2md/releases/download/v2.0.0/course2md-gui-macos-arm64.dmg) | 退出旧应用，将完整 `course2md.app` 放入「应用程序」 |
| Windows x64 | [桌面 ZIP](https://github.com/mizorewww/course2md/releases/download/v2.0.0/course2md-desktop-windows-AMD64.zip) | 完整解压，打开 `course2md-desktop.exe`，保留同目录的引擎 |
| Linux x64 | [桌面 tar.gz](https://github.com/mizorewww/course2md/releases/download/v2.0.0/course2md-desktop-linux-x86_64.tar.gz) | 完整解压，运行 `./course2md-desktop`；预编译包基于 Ubuntu 24.04 |

处理视频需要 ffmpeg/ffprobe，在线视频还需要 yt-dlp；安装 aria2 后模型多线程下载。桌面安装包已内置 yt-dlp，Windows 桌面包还内置 aria2；手动安装 ffmpeg 请参阅 [安装指南](https://github.com/mizorewww/course2md/wiki)。Intel Mac 和 Linux ARM64 提供独立 CLI，暂不提供预编译 GUI。

**独立 CLI**：macOS / Linux 可运行

```sh
curl -fsSL https://raw.githubusercontent.com/mizorewww/course2md/v2.0.0/install.sh | bash
```

也可下载本页 `course2md-macos-arm64`、`course2md-macos-x86_64`、`course2md-linux-x86_64`、`course2md-linux-aarch64` 或 `course2md-windows-x86_64.exe`，改名为 `course2md`（Windows 为 `course2md.exe`）并放入 PATH 中的目录；Unix 可执行文件需赋予执行权限。手动安装 Apple Silicon CLI 时，还需下载 `mlx-macos-arm64.metallib`，改名为 `mlx.metallib` 放在 CLI 同一目录。

## 升级

**从 1.7 升级**：Homebrew 运行 `brew update && brew upgrade --cask course2md-gui`（CLI 为 `brew upgrade course2md`），AUR 照常更新；手动安装时退出旧应用，替换整个应用或解压目录。

- 已下载的识别模型、Bilibili 登录，以及 CLI 的 `config.toml` 继续使用，无需删除。
- 2.0 桌面应用不再读取 1.x 的设置，首次打开会显示引导，识别方式和 AI 服务需要重新设置。
- 1.x 生成的笔记保留在原目录，仍可用编辑器或浏览器打开，但不会出现在 2.0 的笔记库中；需要在笔记库中阅读时请重新转换。
- 2.0 的任务和笔记版本记录无法由 1.x 管理，降级前请留意。

**从 RC 改回正式版**：先退出应用，卸载 RC cask（不要加 `--zap`，以保留用户数据），再安装正式版；配置、笔记和模型缓存都会保留。

```sh
brew update
brew uninstall --cask course2md-gui@rc
brew install --cask mizorewww/tap/course2md-gui
```

用过 RC 版独立 CLI 的用户：

```sh
brew uninstall course2md-rc
brew install mizorewww/tap/course2md
```

启动后在「设置 → 应用」确认版本 `2.0.0`；CLI 使用 `course2md --version` 确认。

本版界面已在 macOS 上逐页运行检查；Windows 与 Linux 版本只经过自动构建和测试。如遇问题请[反馈](https://github.com/mizorewww/course2md/issues)。

## English

**course2md 2.0** is the first stable 2.0 release and replaces 1.7.0 as Latest. It rebuilds the desktop app around a Material 3 design with 10 themes, text sizes and reduced motion, in English, Simplified Chinese, Traditional Chinese and Japanese. Paste a link or drop a local video on Home, review the preview and options, and click **Start conversion**; multi-part Bilibili videos and playlists can be queued in one batch. Tasks run in the background and can be paused, resumed and reordered; a partial result can be read first and only its failed parts redone, and reprocessing keeps the previous version. The library has a folder tree with nested folders, drag and drop, search across subfolders, several library locations and deletion to the trash. The reader adds a summary card, outline, find, a Screenshots view with a zoomable viewer, remembered reading positions and HTML export with images. A four-step setup covers recognition, AI services, Bilibili and model download. Service keys are stored in the system keychain.

With AI processing on, formulas (including spoken ones) are written as LaTeX and rendered, and notes can be bilingual in eight languages (`--translate <LANG>` in the CLI). Ollama and a ChatGPT subscription (via the Codex login) join OpenAI-compatible services. Models download from ModelScope or hf-mirror.com in mainland China, resume after interruptions, are checked with SHA-256, use aria2 when installed, and show size, speed and time left. The CLI gains `--lang`, `--translate`, `--summarize`, `--login ollama|codex` and stable error codes in `--json`. Since RC17: everything in RC18, text selection and copying in the reader (formulas copy as their original LaTeX), and long text beside an enlarged screenshot is fully readable.

**Install:** `brew install --cask mizorewww/tap/course2md-gui` (Apple Silicon) or `yay -S course2md-gui-bin` (Arch x64), which also install ffmpeg, yt-dlp and aria2; or use the platform downloads above. Desktop packages bundle yt-dlp, and the Windows package also bundles aria2; install ffmpeg yourself. The standalone CLI is `brew install mizorewww/tap/course2md`, `yay -S course2md-bin`, install.sh or the release binaries.

**Upgrading from 1.7:** downloaded models, the Bilibili login and the CLI's `config.toml` keep working. The 2.0 desktop app does not read 1.x settings, so the setup guide runs again and AI services need to be added again. Notes made by 1.x stay on disk as Markdown/HTML but are not listed in the 2.0 library; convert again to read them there. 1.x cannot manage 2.0 task and note-version records.

**Moving from RC to stable:** quit the app, run `brew uninstall --cask course2md-gui@rc` (without `--zap`, so your data stays), then `brew install --cask mizorewww/tap/course2md-gui`. For the CLI, replace `course2md-rc` with `course2md`. Confirm version `2.0.0` in Settings → Application.

The interface was checked by hand on macOS; the Windows and Linux builds were tested automatically only. Please report any issues.
