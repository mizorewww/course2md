# v3.0.1：幻灯片截图与检测到的画面一致

3.0.1 是 3.0.0 的修复版。

## 修复

- **笔记里的幻灯片截图有时是上一页**：检测幻灯片时取样的画面和随后截取的图片可能不是同一帧；如果翻页恰好落在两者之间，笔记会在新一页的位置放上旧一页的截图。现在截图就是检测时取样的那一帧（slide-detect 0.1.1）。页面出现的时间点不变。

## 其他

- 界面组件库更新到 `material-v0.3.0`（随 GPUI 引擎一起更新），界面外观和操作不变。

## 安装

GUI 包含同版本 CLI 引擎，无需另装 CLI。3.0.1 是正式版，Homebrew 与 AUR 的稳定通道都会更新。

- macOS Apple Silicon：`brew upgrade --cask course2md-gui`，首次安装用 `brew install --cask mizorewww/tap/course2md-gui`
- 独立 CLI：`brew install mizorewww/tap/course2md`（升级用 `brew upgrade course2md`）
- Arch Linux（x86_64）：`yay -S course2md-gui-bin`（GUI）或 `yay -S course2md-bin`（CLI）

| 平台 | 安装包 | 使用方式 |

## English

**course2md 3.0.1: slide images match the detected slide.** A slide image could show the previous slide when a slide changed between the moment the scan sampled and the moment the image was taken, so a note placed the old slide under the new one's heading. Each image is now the very frame the scan sampled (slide-detect 0.1.1); slide times are unchanged. The UI component library moves to `material-v0.3.0` (with its GPUI engine); the interface looks and works the same.

**Install:** `brew upgrade --cask course2md-gui` (Apple Silicon), `brew install mizorewww/tap/course2md` for the CLI, `yay -S course2md-gui-bin` or `yay -S course2md-bin` on Arch x86_64, or use the downloads in the table above. The Windows installer is unsigned, so SmartScreen asks first (**More info → Run anyway**). Settings, model caches and libraries are kept.
