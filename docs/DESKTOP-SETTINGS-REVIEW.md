# 设置、引导与动效复审

本轮由独立子代理操作真实 macOS 应用验收。任何有证据的设计问题均需处理，不以对齐、对比度、测试通过三项替代完整设计审查。

## 基线问题

子代理在实际窗口确认了目录输入与按钮高度错位、设置页签选中态过浅、运行环境正常状态仍突出安装命令、诊断按钮像输入框、首次引导缺少任务说明。键盘焦点因自动化工具状态滞后暂列待复核，不直接认定产品缺陷。

## 本轮约定

- 设置内容最大宽 760px；页面边缘 24px，分组内部 16px，组间 24px。分组标题、说明与字段共用内部起始线。
- 输入与配套目录按钮均为 36px，目录操作不使用省略号截断标签。即刻生效的偏好用尾部对齐开关，偏好行至少 44px；多选导出格式有勾选标记及明确选中底色。
- 设置页签、转录来源的选中状态使用蓝底白字，并提供可访问的选中语义。识别卡同时使用明显边界和单选点，不只依赖浅色底。
- 运行环境默认面向视频处理、在线链接、本机识别三项能力。命令、工具列表、模型下载和配置文件放在按需展开的诊断中。云端服务是可选方案，不影响本机能力是否可用。
- 首次引导说明用户需要确认什么以及之后在哪里修改；本机自动选择，云端字段按需展开。弹窗底部操作固定，表单可滚动。
- AI 服务说明靠近开关，关闭时隐藏无关字段。
- 关于页显示软件版本、真实构建提交和项目/许可证入口，不填充未知版本。

## 动效实现与验收要求

动态配置与诊断展开使用 GPUI Component 同源码中的 gpui-base Spring / MotionReveal：280ms 响应、临界阻尼，无过冲；反向操作沿当前速度继续过渡，同时测量真实内容高度。开关使用组件原生弹簧反馈；设置内容切换使用 140ms cubic-bezier(0.2, 0, 0, 1) 淡入。减少动态效果立即生效，不以持续帧循环维持静止页面。

子代理验收需覆盖默认/选中/错误/展开/收起/减少动态效果、键盘实际操作、最小窗口与关于页。记录截图及未能验证的范围；有问题则修改后复验。

## 独立实机复审记录

使用独立临时配置运行打包后的 macOS 应用，未修改用户日常配置。

- 基线 → R1：调整统一布局、选择态、设置分组、引导和能力检查后，子代理发现 GPUI Component 自定义 Size 会改变字体但不提供预期控件高度。改用默认字号与明确的 36px 高度，并修正动态容器宽度。
- R2：实机确认目录输入与按钮对齐、选中态可辨、860×620 窗口页签与滚动可达、关于版本信息、键盘 Tab 和空格开关。继续发现动态区域尾部绘制余量不足、重开引导取消后跳页、错误提示泄漏 CLI 指令；随后修复。
- R3：确认引导取消返回来源页、中文就地校验、完整焦点环、原生关于菜单与隐藏输入焦点。继续发现无关设置错误出现在关于页；改为字段错误只在对应表单显示，保留侧栏未保存标记。

- R4：确认无关页面不展示表单错误、侧栏未保存标记保留、原生关于菜单不抢走引导输入焦点，版本与提交一致。只读审查提出“AI 配置无效时重开引导”的隐藏字段问题，实机复现；增加“前往 AI 设置”修复入口，并仅聚焦引导可见字段，保存失败恢复此前的引导完成状态。
