# 桌面工作区规范

依据 Apple HIG 的 Layout、Toolbars、Progress indicators、Settings、Motion；采用 GPUI Component 的跨平台 TitleBar，遵循用户要求提供系统标题栏选项。参考：
- https://developer.apple.com/design/human-interface-guidelines/layout
- https://developer.apple.com/design/human-interface-guidelines/toolbars
- https://developer.apple.com/design/human-interface-guidelines/progress-indicators
- https://developer.apple.com/design/human-interface-guidelines/motion

以下尺寸是项目约定，不是 HIG 强制数值：4 px 基础网格；控件间距 8、行内 12、组内 16、组间 24；页面左右统一 24；侧栏 200；正文 14、辅助 12、标题 18；表单控件与输入统一 36，紧凑工具按钮 32；圆角 6。所有页面、弹内编辑区、提示与工具栏共享左右对齐线，不再单独居中产生多套边缘。

## 减法

移除品牌卡、页面副标题、重复操作说明、默认成功提示、底部解释段落与设置保存按钮。空状态只保留一句状态和一个动作。仅保留影响用户决定的信息（上传到远端、错误及恢复方法）。课程确认卡保留封面、标题、作者/时长、文件夹与生成操作。

## 工作区与设置

默认自定义标题栏，保留平台窗口控制及拖动行为；页面名与操作放在内容工具栏。空闲不显示底栏；任务运行时仅显示真实任务摘要，可进入任务详情。使用系统标题栏的偏好自动保存，重启生效；避免重建窗口导致运行中任务中断。设置输入防抖保存，有效值落盘；无效值留在输入框并显示错误，不悄悄替换为默认值。单次任务选项不写入默认设置。

## 真实反馈与并行

任务展示动态工作项；下载分别显示文件名、字节、速度、估算剩余时间；转写显示已完成片段/总片段及估算时间。首次采样和未知总量显示正在估算，不编造百分比；等待、加载模型、运行、失败、取消、完成各有静态标签。截图与音频/转写流水并行；两个独立模型文件并行下载。UI 明确列出同时运行的工作。

## 动效与性能

采用短时 ease-out 三次曲线进行内容确认、状态转换和进度变化；不把动画当作等待时间，不动画每次输入或重复导航。提供减少动态效果选项。事件发送节流，闲置 UI 不因日志/计时器反复重绘；阅读内容避免深拷贝，昂贵工作保持后台运行。

## 验收

先实现再测试：真实在线预览、本地转换、下载及转写状态、并行工作项、自动保存失败/恢复、标题栏重启切换、键盘与窗口缩放、减少动效。使用独立验收目录，原子提交；不保留模拟成功的脚手架测试。

设置、引导、运行环境与关于页的最新布局及独立实机验收标准见 [设置复审](DESKTOP-SETTINGS-REVIEW.md)。
