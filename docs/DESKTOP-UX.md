# 原生课程库 UX 设计

## 产品重心

用户来这里积累与阅读课程笔记。启动进入课程库，主动作是「添加课程」，不是填写转换表单。保留安静、温暖的底色，用深蓝色标记当前选择和主要动作。侧栏承担导航与文件夹，内容区呈现封面、标题和笔记概况，不再堆叠配置卡片。

## 三条完整路径

1. 在线课程：添加课程 → 默认「在线链接」→ 粘贴 YouTube / Bilibili 地址 →「预览课程」→ 确认真实封面、标题、作者与时长 → 选择文件夹 →「生成笔记」。修改地址后旧预览立即失效，慢请求不能覆盖新地址。解析中显示明确反馈；解析失败保留地址并允许重试。封面不可用时明确显示占位，不冒充真实封面。
2. 本地课程：切换「本地视频」→「选择视频」→ 自动读取视频信息与封面 → 确认并生成笔记。两个入口不混用动作标签。已选来源在返回页面时保留。
3. 整理与阅读：全部课程 / 未分类 / 文件夹 → 搜索标题 → 打开笔记 → 返回原来的列表。支持新建、重命名、删除文件夹，课程可以移动到其他文件夹或未分类。删除文件夹只取消分组，保留课程及导出文件。

## 信息与视觉层级

- 固定侧栏：品牌、添加课程、全部课程、未分类、文件夹列表、新建文件夹；任务与设置靠下。
- 课程库：当前文件夹标题、数量、搜索；封面网格，标题最多两行，轻量元信息；课程操作菜单提供移动。
- 添加页：返回课程库、来源切换、链接输入与预览按钮；确认卡用大封面建立内容识别；归档目标清晰可选；识别与输出为按需展开的次级选项。
- 主要动作固定在页面底部。尚未确认来源时不可生成；忙碌任务显示「查看当前任务」，不伪装为新任务入口。
- 文件夹编辑使用一个紧凑、可取消的编辑区域，错误就地显示。空课程库提供添加入口；空文件夹说明添加的新课程可自动归档；搜索无结果不冒充空课程库。

## 数据与实现边界

文件夹是课程库内的逻辑分组，独立于 CLI 输出路径，避免移动破坏资源引用和重复下载缓存。元数据保存在当前课程库目录，原子写入；损坏文件必须报告并保护原文件。正在生成的任务捕获启动时的来源、封面和归档目标，不跟随之后的编辑变化。在线预览通过 yt-dlp 读取真实信息；本地预览通过 ffprobe / ffmpeg。工具在后台运行并有超时，UI 不阻塞。课程封面持久保存，失败不影响已完成的笔记。

## 验收标准

实际操作检查：启动课程库、在线粘贴与预览、来源切换、修改链接后失效、失败重试、本地视频封面、生成并阅读、创建/重命名/删除文件夹、移动课程、重启后保留分组、搜索空状态。测试在实现稳定后覆盖实际数据丢失与状态竞态风险，不添加脚手架测试。每个可审查的工作单元独立提交。
