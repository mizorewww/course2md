# 首次使用与控件可辨识度修正

## 审查结论

- 首次启动缺少设置入口引导，也没有展示可用识别方式。新增首次设置弹窗，直接完成识别方式与笔记目录选择；明确后续在设置中修改，允许稍后设置，并可从设置重新打开。
- 原「就绪」仅代表 CLI / ffmpeg / ffprobe 文件存在，不代表识别能力。删除该标签；能力检测区分别报告工具、后端和配置，底栏展示真实任务或所选方式及缺失条件。
- 原控件边框 `#e3e5e2` 对白底仅约 1.27:1；未选中复选框及次要按钮难以辨认。控件边框与分隔线分开，前者目标至少 3:1；正文和辅助文字至少 4.5:1。不靠颜色单独表示可用/不可用、选中/未选中。
- 创建课程时，在预览完成前隐藏不能执行的「生成笔记」，让「预览课程」成为明确下一步。来源输入保留可见标签，选项有明确边界与分组。

## 流程

首次打开主窗口后立即显示设置弹窗，后台检测真实工具和可枚举的设备，不等待模型下载。引擎行展示已检测的能力、未安装项及需要配置项；可用引擎可直接选择，API 可进入填写配置。默认推荐已检测到的本地方式，不把未验证的 GPU / NPU 推理宣称为可用。

保存目录提供默认值与目录选择器。完成后保存首次设置标记并进入添加课程；跳过只记录已看过引导，不覆盖原有配置。关闭应用后再次启动不重复打扰已完成或跳过的用户。首次标记不得通过日常自动保存误置。

## 依据与验收

依据 Apple HIG 的 Onboarding、Offering Help、Buttons、Layout、Accessibility，以及 WCAG 2 的文字/非文字对比度要求。项目使用 GPUI Component 原生对话框管理焦点与遮罩，不用手写覆盖层替代模态行为。尺寸是项目约定，不宣称通过完整 WCAG 或 VoiceOver 认证。

验收包含全新配置启动、检测中/检测结果、完成/跳过/重启、缺失工具、设置重新打开、键盘焦点、对比度测量和小窗口排版。先实现后验证，不保留脚手架测试。
