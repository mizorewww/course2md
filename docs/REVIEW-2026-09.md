# 2026-09 代码审查与原生客户端验收

审查范围：Rust CLI 的配置、媒体获取、字幕/语音转写、断点、场景检测、LLM、输出和模型缓存；Apple 桥接构建；Tauri 进程管理；新增 GPUI 客户端、依赖准备与三平台打包。以下是本次确认并修复的问题，不代表对所有硬件和第三方服务的穷举验证。

## 修复与结构调整

| 问题 | 修复 |
| --- | --- |
| 同名临时文件和输出竞争，失败后留下半成品 | 使用唯一临时目录、同目录原子替换；音频成功提取后才发布；课程和模型缓存加入进程间独占写锁 |
| 中断导致首条 checkpoint 被截断后无法恢复 | 只修复未完成的最后一行，完整但损坏的记录仍明确报错 |
| 字幕任务被无关的 ASR 工具/密钥检查拦截 | 把 ASR 检查移动到实际启用识别时；远程元数据仍检查 yt-dlp |
| 无效数字被静默钳制、ROI 非有限数漏检 | 删除静默纠正，给出明确参数错误 |
| NPU 自定义模型仓库名被小写化、别名解析不一致 | 共用别名映射，保留仓库名大小写，修正 whisper-large 映射 |
| 相同字幕跨长停顿被合并、无效时间区间混入 | 仅合并重叠的相同字幕，校验时间范围 |
| API 端点切换仍可能复用旧识别结果 | 端点加入缓存身份；本地视频指纹增加纳秒精度 |
| 转录接口使用服务专有 JSON，缺失响应字段被视为空语音 | 使用 multipart 的 file/model 上传；缺少字段报错；共享 HTTP 重试并支持 429 |
| LLM 尾逗号修复误改字符串中的 `,}` 或 `,]` | 使用识别 JSON 字符串和转义状态的扫描逻辑 |
| 本地视频链接不可用，远程链接重复 t 参数 | 本地生成编码后的 file URL；替换已有 t 参数并处理片段 |
| 配置文件启用保留视频后无法单次关闭 | 增加 `--no-keep-video`，与启用选项互斥 |
| Tauri 完成事件早于输出、取消与退出存在竞态 | 有界日志通道、定时批量刷新、读完输出再发布完成；同一 supervisor 管理取消/回收；退出等待进程清理 |
| Tauri 配置替换可能降低密钥文件权限 | 复用私有临时文件原子写入和私有备份方式 |
| CLI 和新桌面端容易重复维护配置规则 | 将配置合并抽至 `src/options.rs`；桌面设置直接复用核心校验 |

未将整个项目重写为通用框架。新增桌面端把进程与课程文件访问放在 `backend.rs`，状态和动作放在 `main.rs`，视图放在 `views.rs`。删除了静默钳制、字符串全局替换和临时路径拼接等有具体风险的做法。对未知协议字段、外部服务错误、文件损坏和子进程取消保留必要检查。

## GPUI 客户端

提供本地文件选择和链接输入、字幕优先/仅字幕/识别模式、六种后端选项、三种输出格式、进度和取消、课程搜索、含本地截图的笔记预览、配置编辑、环境检查和模型下载入口。任务成功以引擎成功退出且收到完整结果为准；关闭运行中的窗口先清理进程。

开发前已更新 `~/Developer/zed` 和 `~/Developer/gpui-component` 的 main。独立工作树中的小型兼容覆盖连接组件主线的 `gpui-pre` 包名与 Zed 的原始 GPUI；原仓库不受覆盖修改。覆盖内容集中于准备脚本，上游布局变化会报错。开发默认追踪 main，发布使用 `desktop/sources.lock.json` 中实际测试的提交和 Cargo 锁文件。

macOS 最终可执行文件添加 Swift runtime rpath；MLX shader 按上游加载规则与 CLI 放在同一目录，避免通过更改工作目录影响相对路径。打包包含匹配的 CLI，并使用 ad-hoc 签名。Windows/Linux 分别输出 ZIP/tar.gz；CI 配置三个平台的构建和桌面测试，tag 使用冻结版本。

## macOS 实际操作

验收用独立 `XDG_CONFIG_HOME`，没有保存或覆盖个人 API 设置。

- 原生选择器选择本地视频；空输入阻止运行；12 秒、三次画面变化的视频配三段中文字幕，经实际 CLI/ffmpeg 输出 Markdown、HTML、JSON 和三张截图。
- 阅读结果中的中文、时间和图片，修正图片原始尺寸挤宽页面的问题；课程库能找到结果，搜索不存在的标题显示空状态。
- 设置界面保存后回读成功，配置文件权限为 0600。
- 启动一小时媒体夹具，运行中取消，确认 CLI 和 ffmpeg 均退出；随后再次启动短任务成功。
- 运行中关闭窗口，确认窗口关闭后没有遗留转换进程。
- 使用本地 HTTP 模拟服务运行真实语音提取和 API 上传，核对 multipart 中的模型字段及 RIFF 音频，成功得到转写结果。这验证传输协议，不冒充真实云端模型调用。
