From “I watched it” to “I can use it”

No more scrubbing the timeline

Flip through an hour-long lecture in minutes. Looking for one concept? Find takes you straight to the slide and the sentence.

Slides and explanation, together

Slides alone don't explain the derivation, and subtitles alone have no pictures. Here, every screenshot sits right above what the lecturer said about it.

Your notes, your files

Saved as plain Markdown and web pages. Drop them into Obsidian or another notes app, print them, or send them to a classmate. No account needed.

Queue up a whole course

Add the semester's lectures and they're processed one by one in the background; pause any time. Finished notes are filed in folders and searchable by title.

Your audio stays on your computer

Speech is recognized locally. Audio or text leaves your computer only if you choose a cloud speech service or an AI service.

Local recognitionDefault
Cloud speech serviceOptional
AI proofreading and summariesOff by default

Download the desktop app

The desktop app includes the conversion engine and also needs ffmpeg. The first local transcription downloads a speech model (1–2.4 GB).

macOS · Apple SiliconmacOS 15 or later Download DMG
Or install with Homebrew, which also installs ffmpeg and yt-dlp $brew install --cask mizorewww/tap/course2md-gui
Windows · x64Portable package: extract everything to a permanent folder, then open course2md-desktop.exe Download ZIP
Install ffmpeg in PowerShell >winget install --id Gyan.FFmpeg -e
Arch Linux / CachyOS · x86_64Installs the video tools and graphics libraries too. Needs a working Vulkan driver. $yay -S course2md-gui-bin
Ubuntu and other distributions · x86_64Built on Ubuntu 24.04. Install ffmpeg and the graphics libraries separately. Download tar.gz
Intel Macs and Linux ARM64 have no desktop app yet; use the command-line version. See the installation guide for details.

Prefer the terminal?

The CLI shares one configuration file with the desktop app, and both can be installed side by side. Handy for batches and scripts, and it also runs on Intel Macs and Linux ARM64.

$curl -fsSL https://raw.githubusercontent.com/mizorewww/course2md/main/install.sh | bash CLI guide
