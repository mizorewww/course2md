一节课，从「看过」变成「能用」

复习不用再拖进度条

一个多小时的课，几分钟就能从头翻到尾。想找某个概念，全文查找直接停在那一页、那一句。

幻灯片和讲解在一起

只看 PPT 看不懂推导，只看字幕又没有图。在这里，每张截图下面就是老师讲这一页时说的话。

笔记是你自己的

存成普通的 Markdown 和网页文件，放进 Obsidian 之类的笔记软件，或者直接打印、发给同学。不用注册账号。

一次排好一整门课

把这学期的课都丢进去，在后台一节节整理，随时暂停。整理好的按文件夹归档，用标题就能搜到。

音频默认不离开你的电脑

语音识别在本机完成。只有你主动选择云端语音服务或 AI 服务时，才会把音频或文字发送出去。

本机识别默认
云端语音服务可选
AI 校对与摘要默认关闭

下载桌面版

桌面版自带转换引擎，另外需要 ffmpeg。第一次在本机识别语音时会下载 1–2.4 GB 的语音模型。

macOS · Apple 芯片macOS 15 及以上 下载 DMG
或用 Homebrew 安装，会一起装好 ffmpeg 和 yt-dlp $brew install --cask mizorewww/tap/course2md-gui
Windows · x64便携版：解压到一个固定的文件夹，运行 course2md-desktop.exe 下载 ZIP
在 PowerShell 里安装 ffmpeg >winget install --id Gyan.FFmpeg -e
Arch Linux / CachyOS · x86_64一起装好视频工具和图形库，需要可用的 Vulkan 驱动 $yay -S course2md-gui-bin
Ubuntu 和其他发行版 · x86_64在 Ubuntu 24.04 上构建；另需安装 ffmpeg 和图形库 下载 tar.gz
Intel Mac 和 Linux ARM64 暂时没有桌面版，可以使用命令行版本。安装细节见安装指南。

也可以在终端里用

命令行版和桌面版共用一份配置，可以同时安装。适合批量处理、写进脚本，也能在 Intel Mac 和 Linux ARM64 上运行。
